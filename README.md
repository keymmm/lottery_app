# Lottery App 🎲

A simple lottery app built with React Native and Expo. Users can place bets on a 3-digit number and see if they win big!

## Features

- Input a 3-digit number and a bet amount.
- Randomly generates a winning number.
- Displays a result message indicating whether the user won or lost.
- Confetti animation for winning bets.
- User-friendly interface with validation for inputs.
